# Wanderlust — Indian Mountain Escapes & Coastal Getaways

## 1. Project Title & Theme

- **Project Title:** Wanderlust — Indian Mountain Escapes & Coastal Getaways
- **Theme:** Travel Agency Website
- **Assignment:** Web Development I — Lab Assignment 5 (Capstone Project)
- **Technologies Used:** HTML5 and CSS3
- **CSS Concepts:** Flexbox, CSS Grid, CSS Variables, Keyframe Animations, Transitions, Hover Effects, and Media Queries.

Wanderlust is a responsive travel agency website designed to showcase beautiful Indian travel destinations, curated tour packages, travel experiences, and essential trip information. The website focuses on providing an attractive and user-friendly interface for exploring mountain destinations and coastal getaways.

## 2. Short Description of Sections Implemented

The website consists of the following sections:

### 1. Header & Navigation
- Brand logo and website name (Wanderlust).
- Navigation links for different website sections.
- Skip-to-main-content accessibility link.
- Plan a Trip call-to-action button.
- Smooth scrolling navigation.

### 2. Hero Section
- Full-width Himalayan mountain background.
- Dark overlay for better text visibility.
- Main heading and introductory tagline.
- Call-to-action button to encourage trip planning.
- Editorial caption and cursor-responsive background effect.

### 3. Popular Destinations
- Four destination cards featuring:
  - Spiti Valley
  - Kasol & Parvati Valley
  - Manali & Solang Ridge
  - South Goa & Gokarna
- Destination images and brief descriptions.
- Responsive card layout using CSS Grid.

### 4. Signature Tour Packages
- Three featured travel packages:
  - Spiti & High-Pass Expedition
  - Manali & Kasol Pine Retreat
  - Goa & Gokarna Cove Escape
- Package duration, ratings, pricing, and included facilities.
- Booking call-to-action links.

### 5. Traveler Photo Board
- Image gallery showcasing mountains, forests, and coastal destinations.
- Captions accompanying travel photographs.
- Responsive gallery layout.

### 6. Sample Itinerary & Traveler Essentials
- Four-day Manali and Solang travel itinerary.
- Day-wise travel activities and schedule.
- Traveler essentials sidebar containing useful travel information.

### 7. Traveler Reviews
- Three traveler testimonial cards.
- Customer feedback and star ratings.
- Traveler portraits and review descriptions.

### 8. Trip Inquiry Form
- Accessible travel inquiry form.
- Required input fields with associated labels.
- Destination selection dropdown.
- Travel month input.
- Additional notes textarea.

### 9. Footer
- Website brand information.
- Navigation links.
- Contact details.
- Copyright information.

## 3. Breakpoints Used & Main Layout Techniques

### Main Layout Techniques

**CSS Flexbox**
- Header and navigation alignment.
- Hero section button alignment.
- Itinerary timeline arrangement.
- Package card content alignment.

**CSS Grid**
- Four-column popular destinations layout.
- Three-column tour package cards.
- Traveler photo gallery.
- Three-column traveler reviews.
- Itinerary and sidebar arrangement.
- Inquiry form and footer layouts.

**CSS Variables**
- Custom properties defined using `:root`.
- Consistent color palette, typography, spacing, border radii, and shadows.
- Reusable styling throughout the website.

**Responsive Units**
- Use of `rem`, `%`, `vh`, and `vw` units for flexible sizing and spacing.

**Animations & Hover Effects**
- Keyframe entrance animation for the hero section.
- Smooth hover transitions on cards and buttons.
- Subtle visual effects to improve the overall user experience.

### Responsive Breakpoints

| Screen Size | Layout Adjustments |
|---|---|
| Desktop (> 1024px) | Multi-column grids and horizontal navigation. |
| Tablet (≤ 1024px) | Two-column card and gallery layouts; stacked itinerary and inquiry sections. |
| Mobile (≤ 768px) | Single-column layouts, stacked navigation, and adjusted spacing. |
| Small Mobile (≤ 480px) | Further adjustments to typography, spacing, and component sizing. |

The website uses CSS media queries to maintain a consistent appearance and improve usability across desktop, tablet, and mobile devices.

## 4. How to Open the Project

### Run Locally

1. Clone or download the GitHub repository:

   ```bash
   git clone https://github.com/himanshiyadav2409-sys/capstone-Himanshi-Yadav-lab5.git
   ```

2. Open the project folder:

   ```bash
   cd capstone-Himanshi-Yadav-lab5
   ```

3. Open `index.html` directly in your web browser.

4. Alternatively, open the project in Visual Studio Code and run it using the Live Server extension.

### GitHub Repository

[Wanderlust — Capstone Lab 5 Repository](https://github.com/himanshiyadav2409-sys/capstone-Himanshi-Yadav-lab5)

### GitHub Pages (Optional)

The website can also be hosted using GitHub Pages.

To enable it:

1. Open the GitHub repository.
2. Navigate to **Settings → Pages**.
3. Under Build and Deployment, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save**.

Once deployment is complete, GitHub will provide a live website link.
